## 各カラムの出典候補

| テーブル.カラム | 意味 | 出典候補 | 取得手段 |
| --- | --- | --- | --- |
| `regions.land_price_per_tsubo` | 坪単価（万円） | 地価公示 / 都道府県地価調査 | 不動産情報ライブラリ **XPT002** |
| 〃（実勢寄りにするなら） | 〃 | 不動産取引価格情報 | 不動産情報ライブラリ **XIT001** |

| `regions.population_trend` | 人口動態 -1.0–1.0 | 国勢調査 / 日本の地域別将来推計人口（社人研） | e-Stat API、または不動産情報ライブラリ **XKT013**（将来推計人口 250m メッシュ） |

| `property_type_factors.*` | 種別ごとの重み | 統計ではなく**このアプリの判断基準**。オープンデータ化の対象外 | — |

### 賃料について

**賃料には国の公的なオープンデータが存在しない。** 不動産情報ライブラリが持つのは
売買の取引価格であって、賃貸の募集賃料・成約賃料は含まれない。選択肢は次のいずれか。

- 民間の賃貸ポータルが公開している統計（利用規約の確認が必須）
- 住宅・土地統計調査の「1 か月あたり家賃」（借家世帯ベース。粒度は粗い）
- 売買価格から表面利回りを仮定して逆算する（近似。前提を明示すること）

現在は最後の考え方に近い仮値が入っているが、**根拠のある算出はしていない**。

## 不動産情報ライブラリ API

国土交通省が提供。API マニュアル: <https://www.reinfolib.mlit.go.jp/help/apiManual/>

### 利用開始

1. <https://www.reinfolib.mlit.go.jp/api/request/> から利用申請する
2. 承認後に API キーが発行される（即時ではない）
3. 全リクエストのヘッダーに `Ocp-Apim-Subscription-Key: {API_KEY}` を付ける

利用規約: <https://www.reinfolib.mlit.go.jp/help/termsOfUse/>

### 使いそうなエンドポイント

ベース URL は `https://www.reinfolib.mlit.go.jp/ex-api/external/{API_ID}`。

| API ID | 内容 |
| --- | --- |
| `XIT001` | 不動産価格（取引価格・成約価格）情報取得 |
| `XIT002` | 都道府県内市区町村一覧取得 |
| `XCT001` | 鑑定評価書情報 |
| `XPT002` | 地価公示・都道府県地価調査のポイント |
| `XKT013` | 将来推計人口（250m メッシュ） |

#### XIT001（取引価格）

```
GET https://www.reinfolib.mlit.go.jp/ex-api/external/XIT001
    ?year=2025&quarter=4&area=26&city=26104&priceClassification=01
```

| パラメータ | 必須 | 内容 |
| --- | --- | --- |
| `year` | ○ | 取引年（取引価格は 2005 年〜、成約価格は 2021 年〜） |
| `quarter` | ○ | 四半期 1–4 |
| `area` | △ | 都道府県コード 2 桁 |
| `city` | △ | 市区町村コード 5 桁 |
| `station` | △ | 駅コード 6 桁 |
| `priceClassification` | | `01` 取引価格のみ / `02` 成約価格のみ / 省略で両方 |
| `language` | | `ja` / `en` |

`area` / `city` / `station` のいずれか 1 つは必須。
市区町村コードは `XIT002` で引ける。

レスポンスは JSON（gzip エンコード）。`{"status": "OK", "data": [...]}` の形で、
`data` の各要素に以下が入る。

| フィールド | 内容 |
| --- | --- |
| `TradePrice` | 取引価格（総額） |
| `Area` | 面積（㎡） |
| `BuildingYear` | 建築年 |
| `Structure` | 建物の構造 |
| `Use` | 用途 |
| `DistrictName` | 地区名 |
| `Municipality` | 市区町村名 |

`land_price_per_tsubo` を出すなら、
用途が宅地の取引を集めて `TradePrice / Area` の中央値を取り、
㎡ → 坪（× 3.30578）と円 → 万円の換算をかける。
平均ではなく**中央値**を使うこと（高額物件に引っ張られるため）。

### 注意

- 明示的なリクエスト上限は無いが、短時間に大量アクセスすると制限がかかる。
  **バッチで先に取得して SQLite に入れる**方針にし、リクエストのたびに叩かない。
- レスポンスは gzip なのでデコードが要る。
- 出典の表示義務がある。利用規約を確認すること。

## e-Stat API（空き家率・人口）

政府統計の総合窓口。<https://www.e-stat.go.jp/api/>

- アプリケーション ID の発行が必要（登録は即時）
- 空き家率 → 「住宅・土地統計調査」
- 人口動態 → 「国勢調査」＋ 社人研「日本の地域別将来推計人口」

## 実データへ差し替える手順

`app/seed.py` だけを差し替えれば済むように作ってある。
`app/advice.py`（採点ロジック）と `app/repository.py`（SQL）は触らなくてよい。

1. 取得スクリプトを `scripts/fetch_*.py` として追加する
   （API キーは `.env` から読み、リポジトリに入れない）
2. 取得結果を `data/` ではなく **`seeds/*.csv` などにコミットする**。
   起動のたびに外部 API を叩かないため
3. `app/seed.py` の `PREFECTURE_ROWS` / `CITY_ROWS` を、
   その CSV を読む処理に置き換える
4. 出典と取得日を README に明記する
5. `tests/test_db.py` の件数アサーション（`47 + 12`）を更新する

### 差し替えるまでの表示上の扱い

現在の本文テンプレート（`app/seed.py` の `TEMPLATE_ROWS`）には、
`market` セクションに「本診断の数値は統計からの目安であり、個別の査定額とは差が出ます」
という趣旨の但し書きを入れてある。
**実データを入れるまでは、この但し書きを外さないこと。**
むしろ「実データ未接続」であることを明示する方が誠実。
